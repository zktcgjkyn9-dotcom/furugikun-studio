# BGM

何も指定しなければ、古着くん専用のBGMを自動で作曲して使います（外部の音源を使わないため、著作権表記は不要）。

自分で用意した曲を使う場合：
1. 曲ファイル（mp3 / wav）をこのフォルダに入れる
2. `credits.json` に「ファイル名: クレジット表記」を書く（表記不要の曲は空文字 ""）
3. 商品の `item.json` に `"bgm": "ファイル名"` を書く

商用利用・SNS投稿が許可されている曲だけを使ってください。BGMなしにする場合は `"bgm": "none"`。音量は `"bgm_volume": 0.22`（初期値）で調整できます。
